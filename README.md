🌦️ Agro Weather Advisor

https://spdarshan46.github.io/Agro-Weather-Advisor/

A smart web application that provides real-time weather updates and crop suitability prediction for Karnataka cities.

---

🚀 Features

🌤 Live Weather System
- Real-time weather using OpenWeather API
- 6-Day Forecast
- Temperature unit toggle (°C / °F)
- Wind Speed, Humidity, UV Index
- Auto location detection
- Auto refresh every 15 minutes
- Dark / Light mode with localStorage

🌾 Crop Suitability Prediction
- City-based simulation
- Soil type selection
- Crop selection
- Weather-based suitability check
- Growth phase timeline:
  - Germination
  - Vegetative
  - Flowering
  - Harvest
- Planting date recommendation

---

🛠 Tech Stack

- HTML5
- CSS3 (Custom Variables + Responsive Design)
- JavaScript (Vanilla JS)
- OpenWeatherMap API
- Geolocation API
- LocalStorage
